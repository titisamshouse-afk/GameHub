# 🎮 GameHub

A mobile-friendly gaming dashboard for games, Minecraft servers, friends, and communities.

## Current MVP
- Home dashboard
- My Games
- Minecraft server cards with online/offline state and player counts
- Friends section
- Community section
- Profile section
- Responsive iPad/phone layout
- Search on the dashboard

## Planned
- Real Minecraft server status APIs
- Server add/edit/delete
- Hosting controls where supported
- Friends and presence
- Authentication and cloud data
- Discord/community integrations
- Favorites and game discovery

## Run
Open `index.html` locally or deploy the repository with GitHub Pages.
